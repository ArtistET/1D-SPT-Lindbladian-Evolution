# N=10、U=10 弛豫时间扫描报告（T=10，M=64）

## 结论

`T=8→10` 的 320 条续算轨迹已经全部完成并通过结果、checkpoint 和日志核验。到 `T=10` 时，`t_R/t_D=1` 附近的中心斜率已显著小于初态，并继续向零移动：

- 初态：odd `-0.9565283970`，even `+0.9714583645`。
- `T=8, M=64`：odd `-0.1611544462 ± 0.0352765562`，even `+0.1638692125 ± 0.0409719013`。
- `T=9, M=64`：odd `-0.1058716954 ± 0.0307337570`，even `+0.0904170259 ± 0.0315011345`。
- `T=10, M=64`：odd `-0.0668143743 ± 0.0226884693`，even `+0.0570699704 ± 0.0224154359`。

但是 `T=10` 仍不能判定为时间平台。利用相同轨迹编号和随机数序列做配对时间差后，`T=8→10` 的斜率变化为 odd `3.52σ`、even `3.05σ`；即使只比较 `T=9→10`，odd 仍为 `2.36σ`，even 为 `1.57σ`。因此本实验的具体弛豫时间尚未得到，只能给出当前下界 `T_relax > 10`，下一步应继续相同 `M=64` 轨迹到 `T=12`。

`T=10` 的曲线已经比 `T=8` 更平，斜率绝对值仅为未收敛 `U=0,D=100` 五点参考的约 `2.32/2.02` 倍；但该参考本身存在严重键维问题，且 `M=32→64` 的斜率变化仍不可忽略，所以不能据此宣称已经进入无相变稳态。

## 参数与连续续算方式

```text
N = 10
U = 10
t1 = 0.1, t2 = 0.2, J = 0
tR = 1
tD = 0.98, 0.99, 1.00, 1.01, 1.02
I1 = I2 = IR = ID = 0.1
dt = 0.025
measure_every = 4        # 测量间隔 0.1
Dload = Dmax = 100
Dstepload = Dstep = 20
cutoff = 1e-8
seed = 260903
trajectories = 64 per tD
```

完整时间曲线由同一批轨迹的 `T=0→4`、`4→6`、`6→8` 和 `8→10` 四段拼接。续算使用 `trajectory_rng(seed, trajectory_id, completed_steps)` 跳过此前已经使用的随机数，保持与一次性从零演化一致。no-jump 分支仍采用双站点非厄米 TDVP 指数传播。

初态是历史保存的非 QN MPS，加载键维和演化上限均为 `100`。所有时间段都触及 `Dmax=100`，因此本实验仍没有完成长时间键维收敛检查。

## 时间平台检查

中心斜率随时间的变化为：

| T | odd slope ± SE | even slope ± SE |
|---:|---:|---:|
| 0 | -0.9565284 | +0.9714584 |
| 4 | -0.5271591 ± 0.0514570 | +0.5493315 ± 0.0508611 |
| 6 | -0.2963322 ± 0.0584119 | +0.2760502 ± 0.0502486 |
| 7 | -0.2000220 ± 0.0445503 | +0.1925264 ± 0.0437303 |
| 8 | -0.1611544 ± 0.0352766 | +0.1638692 ± 0.0409719 |
| 9 | -0.1058717 ± 0.0307338 | +0.0904170 ± 0.0315011 |
| 10 | -0.0668144 ± 0.0226885 | +0.0570700 ± 0.0224154 |

若忽略跨时间相关性、简单合并两个时刻的标准误，`T=9→10` 的变化只有 odd `1.02σ`、even `0.86σ`。但相同 trajectory id 在不同时刻高度相关；使用逐轨迹配对差后，相同变化为 odd `2.36σ`、even `1.57σ`，而 `T=8→10` 为 `3.52σ/3.05σ`。因此不能因为非配对误差看似重叠就宣称形成平台。

当前最稳妥结论是：系统已经非常接近平缓形态，但 odd 斜率仍在可分辨地弛豫，`T=10` 不是已验证的平台时间。

## 样本数判断

- `M=32→64` 时，`T=10` 五点均值最大变化为 odd `1.26e-3`、even `1.41e-3`。
- 在整个 `T=8→10` 时间段，`M=32→64` 最大均值变化为 odd `2.19e-3`、even `2.87e-3`。
- `T=10` 中心斜率的 `M=32→64` 变化为 odd `0.0183`、even `0.0375`，与当前斜率误差同量级。

因此 `M=64` 足够决定“时间还需继续延长”，但不足以给出高精度稳态斜率或相边界。应先用 `M=64` 找到候选平台，再把平台时间补到至少 `M=256`；若要定量检验两个数量级的斜率差，仍建议进一步检查 `M=512` 和更密的参数点。
