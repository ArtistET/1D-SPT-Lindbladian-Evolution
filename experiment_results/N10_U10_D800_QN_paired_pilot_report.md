# N=10、U=10：D400/D600/D800 同轨迹长时 pilot（2026-10-25）

## 设置与原始数据核验

只取 `tD=0.98/1.00/1.02`、各 trajectory id `1:4`；三档传播键维均加载**同一份 QN D400 初态**，使用同一随机种子 `260903`，`dt=0.025`，`T=12`，每条轨迹 480 步、121 个测量点。此比较只隔离传播键维，不能检验初态 D400 或时间步长误差。

`validate_d600_pilot.jl 800` 对 D400/D600/D800 各 12 份结果及其末态 checkpoint（共 36 对）逐文件核验了 JLD2 可读、参数、`completed_trajectories=1`、时间网格、观测值有限性、概率、分支权重、跳跃索引、QN、范数、键维和中间键 Schmidt 谱。D800 最大范数偏差 `1.11e-16`，每步总跳跃概率 `0.0111504–0.0119716`，所选分支权重 `4.37e-5–0.988409`。12 份 D800 单轨迹日志均正常保存最终结果，未见 ERROR、NaN、OOM、负概率或 survival tolerance 异常；外层启动器正常结束。完整数值输出见远端 `log/validate_d800_pilot_20261025.log`。

三点端点斜率 `(SO(1.02)−SO(0.98))/0.04` 的 T=12 D800−D600 配对差：odd `−0.00094±0.00288`、even `+0.00109±0.00245`。这只是 M=4 的随机样本差，**不显著不等于斜率收敛**。D600/D800 的跳跃序列在 tD=0.98 和 1.00 完全一致，在 1.02 仅一个演化步分支不同；相同随机数耦合不能保证不同 D 的离散分支永远一致。

## Schmidt 尾部与后续决策

12 条 D800 末态的最大键维和中间键维全部等于 `800`；中间键最小**保留** Schmidt 值为 `7.92e-4–1.73e-3`，10 个最小保留值的平方和为 `2.45e-5–8.91e-5`。这些不是丢弃权重，不能据此计算截断误差；但与 D600→D800 的可见 SO 位移共同表明 D800 传播仍不能称键维收敛。

下一步先对相同初态、同编号做更高传播 D 的小规模 pilot，并与 D800 配对检查是否继续系统性位移；同时独立量化 U=10 初态从 D400 提高的影响。只有传播键维与初态两种误差得到约束后，才适宜把样本扩展到 M128/256 来压低统计误差。还需另做 `dt=0.0125` 的系综/配对步长检查，并用明确的配对时间窗精度判断是否需要 T14/16。当前 D800/M4 不支持正式的相界、长时平台或整条 SO 曲线收敛结论。
