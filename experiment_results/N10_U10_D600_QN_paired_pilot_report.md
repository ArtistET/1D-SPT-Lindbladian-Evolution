# N=10、U=10：D400→D600 同轨迹长时 pilot（2026-10-22）

## 设置与核验

仅取 `tD=0.98/1.00/1.02`、各 trajectory id `1:4`，同一份 QN D400 初态、相同随机种子 `260903`、`dt=0.025`、`T=12`，只将传播的 `Dmax` 从 400 改为 600。每条轨迹有 121 个测量时间点、480 个演化步。本 pilot 隔离的是**传播键维**，没有检验 D400 初态自身的误差。

`validate_d600_pilot.jl` 逐文件读取并检查了 12 份 D600 和对应 12 份 D400 结果、各自的 T=12 checkpoint：参数、`completed_trajectories=1`、时间网格、复数 SO 的有限性、概率、分支权重、跳跃索引、QN、范数和末态键维均通过。D600 的范数最大偏差为 `2.22e-16`，每步总跳跃概率范围为 `0.0111625–0.0119716`，所选分支权重范围为 `4.37e-5–0.988402`。12 份单轨迹日志均正常保存最终结果，没有检出 ERROR、NaN、OOM、负概率或 survival tolerance 异常；外层启动器正常结束。详细逐时刻数值见远端 `log/validate_d600_pilot_20261022.log`。

## 对异常曲线的含义与下一步

12 条 D600 末态的最大键维和中间键维**全部达到 600**；中间键最小保留 Schmidt 值为 `9.93e-4–2.48e-3`，10 个最小保留值的平方和为 `3.55e-5–1.79e-4`。这些是**保留**权重，不能当成丢弃权重，但说明“到达上限”不是只有可忽略的数值零。D400→D600 的晚期 SO 系统性上移，最大配对均值为 `0.001419`，故 D400 的晚期 SO 水平尚未键维收敛；D600 同样不能宣称收敛。

这个小样本 D600 在 T=12 的六个 parity×参数点均仍低于独立自由费米子计算的相应 U=0 基态 SO；但 M=4 的抽样不确定性尚不足以用它重新判定交叉显著性，正式交叉证据仍来自 D400/M64。下一步以**相同 D400 初态及编号**再做 D800 pilot，检查 D600→D800 差值是否减小；若仍触及上限或差值可观，还要继续更高传播 D 或采用替代截断诊断，并单独提高 U10 初态键维。之后才能进行长时 `dt=0.0125` 与样本量检验。不能把本次 4 条轨迹的斜率差“不显著”解释成收敛。
