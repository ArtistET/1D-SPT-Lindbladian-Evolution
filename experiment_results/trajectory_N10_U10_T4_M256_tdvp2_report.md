# N=10、U=10 长时间量子轨迹实验报告（T=4，M=256）

## 结论

在与早期实验相同的物理参数下，把演化时间从 `T=0.5` 延长到 `T=4`，并把独立轨迹数增加到 `M=256` 后，`t_R/t_D=1` 附近的 odd/even string-order 曲线斜率已经与初始基态产生清楚且统计显著的差异。

- 初态中心斜率：odd `-0.9565283970`，even `+0.9714583645`。
- `T=4` 中心斜率：odd `-0.4747839721 ± 0.0261204430`，even `+0.4952725948 ± 0.0277745704`。
- 相对初态的斜率变化分别为 `+0.4817444249` 和 `-0.4761857697`，约为 `18.4` 和 `17.1` 个 `T=4` 标准误。

因此，“演化态与初始基态在中心斜率上存在可见差距”这一目标已经达到。加入现有 `U=0` 数据后，`T=4` 的斜率绝对值仍约为 `U=0, D=100` 曲线的 `16.5–17.5` 倍；但这组 `U=0` 数据没有键维收敛，不能作为可靠相界参考。另一方面，演化曲线在 `T=3→4` 之间仍有显著变化，所以无论如何都还不能判定已经进入长时的无相变状态。

## 参数与数值方法

```text
N = 10
U = 10
t1 = 0.1, t2 = 0.2, J = 0
tR = 1
tD = 0.98, 0.99, 1.00, 1.01, 1.02
tR/tD = 1/tD
I1 = I2 = IR = ID = 0.1
dt = 0.025
tsmax = 160
T = 4
measure_every = 4  # 图上相邻测量时刻间隔为 0.1
Dload = Dmax = 100
Dstepload = Dstep = 20
cutoff = 1e-8
seed = 260903
trajectories = 256 per tD
```

no-jump 分支使用双站点非厄米 TDVP 指数传播，而不是已经确认在 jump 后失效的一阶 Euler `K0`。每个物理参数点使用相同的轨迹编号和基础 seed，形成 common-random-number 配对。

初态是历史保存的非 QN MPS，加载键维和最大键维均为 `100`。所有正式轨迹都触及 `Dmax=100`，所以本实验不能排除长时间 MPS 截断误差；`Dmax=100` 与 `150` 的 `T=2, M=4` 预检查差异小于 `4e-4`，但仍不等价于完整的长时间键维收敛证明。

## 样本数检查

- `M=128 → 256` 时，`T=4` 五个参数点的最大均值变化为 odd `5.11e-4`、even `1.71e-4`。
- `M=256, T=4` 的最大标准误为 odd `1.02e-3`、even `1.06e-3`。
- 若把所有记录时刻都计入，`M=128 → 256` 的最大均值变化为 odd `2.27e-3`、even `1.70e-3`；所有时刻的最大标准误为 odd `1.28e-3`、even `1.19e-3`。

这支持停止在 `M=256` 来回答本次“是否出现可见斜率差异”的定性问题，但不应写成整条时间曲线已经严格统计收敛。若要定量比较两个数量级的斜率差、做 `Δ→0` 拟合或给出高精度临界结论，建议继续到 `M=512` 并增加更密的临界附近参数点。

就统计精度而言，`M=256` 已足够描述当前演化曲线：`T=4` 斜率的相对标准误约为 `5.5%`，与 D=100 参考的差距超过 `16` 个标准误。当前限制不再主要是轨迹样本数，而是演化时间和 `U=0` 参考自身的键维收敛。

演化时长则还不够。中心斜率在 `T=3→4` 仍从 odd `-0.6284±0.0308` 变到 `-0.4748±0.0261`，even 从 `+0.6300±0.0255` 变到 `+0.4953±0.0278`，变化分别达到 `3.80` 和 `3.57` 个合并标准误，说明尚未形成时间平台。下一步应优先延长 `T`，而不是先单纯增加 `M`；为了控制成本，可以从已保存的 `T=4` trajectory checkpoint 先续算 `M=64–128` 到 `T=6/8`，找到斜率平台后再把目标时间补到 `M=256–512`。

## 传播器验证与运行完整性

- 本地 `N=4` QN 回归测试共 `76/76` 项通过。
- 强制 jump 后，`dt=0.05, 0.025, 0.0125` 的最大生存概率误差分别约为 `2.70e-4, 6.74e-5, 1.68e-5`。
- `dt=0.025` 与 `0.0125` 的最终 odd/even SO 差均约 `1.8e-7`，态 infidelity 约 `1.8e-6`。
- M=256 的五个参数点均由分析器成功重建为完整轨迹编号 `1:256`；轨迹 `1:4` 使用 `T=0→2` 与 `T=2→4` 两段拼接，其余为直接 `T=0→4`。
- 主批次只有 `tD=1.02` 的轨迹 144、145 因慢节点达到 12 小时时限；排除该节点后的 rescue 作业均成功完成。最终 Slurm 队列为空。
- 对正式 `dt=0.025, tsmax=160` 日志检索，没有发现 `ERROR`、`NaN`、负概率、survival tolerance 越界或 OOM；完成日志以最终 JLD2 文件保存结束。
