# N=10、U=10：D400/D600/D800/D1200 配对传播核验（2026-10-30）

## 结论与范围

D1200 的 12 条轨迹全部完成并通过逐文件核验，但仍不能认定传播键维收敛：在 T=12，D1200−D800 的六项实部 SO 配对均值差全部为正，为 **+0.000526–0.000804**，约占 D1200 对应 SO 的 3.0%–4.5%；12 个末态均达到 D1200 上限。此位移与上一档 D800−D600 的 +0.000389–0.000684 同量级，不能用现有档位给出可靠的无穷键维外推或剩余误差上界。

三点 `tD=0.98/1.00/1.02` 各使用相同 id `1:4`、seed `260903` 和**同一份 QN D400 初态**；仅传播 Dmax 不同。其他参数为 N=10、U=10、tR=1、t1=0.1、t2=0.2、J=0、I1=I2=IR=ID=0.1、cutoff=1e-8、dt=0.025、T=12、每 4 步测量一次。下列误差均是 4 对轨迹的标准误，不是置信区间或系统误差界；各时间、各参数点之间存在相关性，六项同号不能当成六次独立统计检验。

## 原始文件与日志核验

`validate_d600_pilot.jl 1200` 在服务器对四档各 12 份结果及末态 checkpoint（共 **48 对**）检查：JLD2 可读、模型及数值参数、completed_trajectories=1、121 点时间网格、480 步记录、复 SO 有限性、概率范围、正分支权重、跳跃索引范围、键维范围、20 个站点全部带 QN、范数和结果/checkpoint 键维一致性；四档 t=0 SO 一致至 1e-10。checkpoint 本身只保存 psi，参数核验来自配对结果的 args，不声称 checkpoint 含有独立参数元数据。

D1200 最大范数偏差 1.11e-16，总跳跃概率范围 0.0111432–0.0119716，所选分支权重范围 4.37241e-5–0.988460。12 份单轨迹日志各有一次最终保存，未发现 ERROR、NaN、OOM、负概率或 survival tolerance 异常；外层日志以 `D1200 pilot launcher finished` 结束。D800 与 D1200 的 12 条轨迹、共 5760 步跳跃分支完全一致，因此本组差异未混入分支切换，但仍有不同轨迹之间的响应差异。

远端复现脚本为 `validate_bond_pilot_20261030.jl`，完整核验输出为 `log/validate_d1200_pilot_20261030.log`（本地 log 也留存一份）；保留了远端原有未跟踪验证脚本。所有六组键维配对、三点、两种 parity、121 个时间点的均值和配对误差见 [完整时间曲线 CSV](N10_U10_D1200_paired_timecurves.csv)，共 4356 行数据。

## 后续决策与尚未解决的误差

继续同 D400 初态的 D1600、三点各 M4 传播 pilot，以检验下一档位移；同时将五个 U10 QN 初态从 D400 提升到 D800/Dstep100，独立核验能量、SO、QN、范数和保留谱，必要时再比较固定传播 D 下的初态影响。D1600 启动器采用三并发，初态 DMRG 顺序运行一份，合计最多四个计算进程，均 nice10、单线程；新路径保留历史数据，初态完成标记只表示程序结束，不表示物理收敛。

统计误差仍需 M128/256 分级复核，当前 M4 仅用来定位传播误差；本轮没有检验 dt=0.0125，步长误差仍待独立系综验证；U0 精确自由费米子参考已可用，但参考精确并不能消除 U10 初态和传播误差。先约束这些误差，再按多个配对时间窗和明确精度决定是否延长 T14/16。当前不得把 D400/M64 或 D1200/M4 宣称为完整可信度验证已完成。
